PMS TOUR & TRAVELS WEBSITE — V1

Included:
- Responsive one-page business website
- PMS branding assets
- Services, About, Gallery, Contact
- Booking form -> WhatsApp booking request
- Call/WhatsApp CTAs
- Tamil/English toggle for key hero/service copy
- SEO title/description and social metadata
- Mobile responsive layout

To publish:
1. Upload this folder to a static host (Vercel, Netlify, GitHub Pages, etc.).
2. Connect a custom domain such as pmstourandtravels.in if available.
3. Create/verify Google Business Profile.
4. Add the final business address, service areas, real vehicle photos and reviews.
5. Add Google Search Console and submit sitemap.xml once the domain is live.

Important:
- This V1 uses WhatsApp for booking confirmation; it does not pretend to have real-time vehicle availability or online payments.
- Before public launch, replace placeholder/stock-style creative with real vehicle and customer photos where appropriate.
